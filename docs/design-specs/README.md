## 状态标记约定

文档中每条规则都标注实现状态，便于开发排期：

| 标记 | 含义 |
| --- | --- |
| 已实现 | 原型代码中已按此规则实现，可直接参考 |
| 待实现 | 原型未实现，需开发补齐 |
| 需服务端 | 前端无法单独完成，依赖接口或后端逻辑 |
| 待确认 | 规则尚未定稿，需产品/业务方拍板 |

「原型」指本仓库的 React 演示工程，仅用于表达交互与视觉意图，**不是**生产实现。原型中的本地状态（Zustand + localStorage）在生产环境应替换为服务端数据。

## 文档之外的约定

- 视觉与组件规范以 Philips Filament 设计系统为准，本文档只描述 Filament 未覆盖的业务规则。
- 文案以文档中给出的中文原文为准，不要自行改写。
